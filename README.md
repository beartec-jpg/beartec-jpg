# Scott Reynolds (BEARTEC)

I'm a physical-world engineer who's gone all in on AI coding. I don't write code by hand. I use my engineering background to plan, test and steer AI tools to build things I couldn't have built alone.

Sites: [beartec.uk](https://beartec.uk) and [falcon-fpl.com](https://falcon-fpl.com)

## Falcon PL

My main project. A blockchain designed to stay secure against future quantum computers. It runs on a public testnet with its own validators, a web wallet, a faucet and bridges to Bitcoin and Ethereum test networks. Outside operators can join using the public installer.

[Falcon-PL](https://github.com/beartec-jpg/Falcon-PL) and [falcon-pl-releases](https://github.com/beartec-jpg/falcon-pl-releases)

## Quantum-safe signatures on Starknet

An experiment that cut the cost of checking quantum-safe signatures on Starknet to less than half of the previous version. It builds on OpenZeppelin's work and is a prototype.

[falcon-starknet-poseidon](https://github.com/beartec-jpg/falcon-starknet-poseidon)

## qBTC

A Bitcoin fork with a faster block structure and quantum-safe signatures from day one. It went through long stress tests without breaking.

[QuantBTC](https://github.com/beartec-jpg/QuantBTC)

## qXRP (retired)

An XRP Ledger fork with quantum-safe signatures. It ran as a fully working testnet, and I retired it to build Falcon PL.

[FalconLedger](https://github.com/beartec-jpg/FalconLedger)

## Cross-chain swaps

Direct swaps between qBTC, Bitcoin, Ethereum, BNB, USDC and XRP, with no middleman holding funds. They were tested and working on a live site.
